# =====================================
#
# 规则格式：<文件路径> <操作> <规则内容>
#
# 文件路径：
#   - 支持相对路径（相对于clash目录）
#   - 自动添加.list后缀（如果没有）
#   - 示例: HongKong, Telegram.list
#
# 操作类型：
#   + : 添加规则到文件
#   - : 从文件中删除规则
#
# 规则内容：
#   必须是有效的Clash规则格式
#   支持的类型: DOMAIN, DOMAIN-SUFFIX, DOMAIN-KEYWORD, IP-CIDR, IP-CIDR6, GEOIP, DST-PORT, SRC-PORT, PROCESS-NAME, RULE-SET
#
# 示例：
#   HongKong.list + DOMAIN-SUFFIX,example.hk
#   Telegram.list - DOMAIN-SUFFIX,t.me
#   Apple.list + IP-CIDR,17.0.0.0/8
#
# =====================================
